# Louis Louisa Booth updates

This is the public download channel for the Louis Louisa Booth Windows app.

It contains installer releases and the signed update files used by installed booths. Application project source is kept in a separate private repository and is not committed here.

GitHub automatically adds "Source code (zip)" and "Source code (tar.gz)" links to releases. These archives contain this repository's README only; they are not archives of the application project.

Download the installer from the latest release. Installed apps can download updates automatically and apply them when the booth is idle.

The installer necessarily contains the runnable client application. It is not an encrypted container for client code.
